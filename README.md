# Guia do Profissional CentralGov — GitHub Pages

Pacote gerado a partir de `index 7.html`, com imagens extraídas para `assets/images/`.

## Publicação

1. Crie um repositório **público** no GitHub (ou use um já existente).
2. Envie **todo o conteúdo desta pasta**, incluindo `index.html`, `.nojekyll` e a pasta `assets`, para a raiz do repositório.
3. Em **Settings > Pages**, selecione **Deploy from a branch**, branch `main`, pasta `/(root)` e salve.
4. Aguarde a publicação e abra `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

Não envie apenas o `index.html`: as imagens agora são arquivos separados e precisam acompanhar o HTML.

## Dependências e observações

- CSS e JavaScript permanecem incorporados ao HTML.
- As imagens são locais, em caminhos relativos, compatíveis com repositórios de projeto do GitHub Pages.
- As fontes Lexend, Source Sans 3 e JetBrains Mono são carregadas do Google Fonts (requerem conexão).
- Há links externos para a Vitrine de Manuais CentralGov e a plataforma Dataprev; esses destinos não fazem parte deste pacote.
- GitHub Pages não fornece autenticação de acesso à página. Verifique se as imagens e informações podem ser divulgadas publicamente antes de publicar.
- Não foi realizado teste visual em navegador nesta preparação.
