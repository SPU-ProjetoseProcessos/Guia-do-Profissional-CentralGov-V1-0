# Guia do Profissional CentralGov

Guia interativo para o servidor da SPU atender tarefas na CentralGov, do login ao desfecho, com as telas reais do sistema.

- **`index.html`** — o guia (página única: imagens, logo, CSS e JS embutidos).
- **`versoes/`** — pontos de restauração congelados (Protótipo 5 e Protótipo 6 = modelo de referência).
- **`docs/modelo-padrao-manuais.md`** — regras do modelo de referência para criar novos guias.

## Publicar no GitHub Pages
1. Suba esta pasta para um repositório.
2. Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. O guia fica em `https://<usuario>.github.io/<repositorio>/`.
